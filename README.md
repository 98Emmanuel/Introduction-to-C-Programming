# Introduction to C Programming

A collection of C programming exercises and implementations developed as part of the **Introduction to Robotics and Mechatronics** laboratory coursework at Ashesi University.

The project focuses on strengthening the fundamentals of the C programming language through practical exercises involving hexadecimal and binary number systems, bitwise operations, user input, functions, compilation, and reusable function libraries.

---

## 📌 Project Overview

This project provides practical experience with fundamental C programming concepts, including:

- Basic C syntax and program structure
- Compiling C programs using GCC
- Working with hexadecimal and binary number systems
- Reading user input from the terminal
- Creating and using function libraries
- Bitwise operations
- Bit shifting
- 16-bit and 32-bit integer manipulation
- Combining hexadecimal values
- Building and compiling programs using a `Makefile`

The exercises progressively build from simple C programs to a small command-line calculator capable of performing hexadecimal operations.

---

## 🎯 Learning Objectives

The main objectives of this project are to:

1. Understand the fundamentals of the C programming language.
2. Work confidently with hexadecimal and binary representations.
3. Understand and apply bitwise operators.
4. Implement reusable functions in C.
5. Create and use header files and function libraries.
6. Read hexadecimal values from the terminal.
7. Manipulate 16-bit and 32-bit integer values.
8. Compile and link multiple C source files.
9. Use a `Makefile` to automate compilation.
10. Develop a structured approach to solving programming problems.
